# 数据来源与版本

## 来源

| 项 | 值 |

本 Vault 里的技能数值、冷却、可学等级、天赋层列，均取自该站 `data.js` / `data-codex.js` 两份数据层文件，
对应站点自述的 **beta 客户端** 口径。

## 版本框架（影响键位设计的部分）

- 60 级永久上限，天赋 **51 点**，三系七层，`11 / 21 / 31` 核心大招保留。
- 每棵树在更深层多出一个**全新核心技能**（经典旧世没有）。
- 一批「只堆 BUFF」的过路天赋被移出天赋树，**改为职业自带基础技能**。
- 官方目标：**27 个专精都能进组**。
- 战斗节奏：单杀普通怪 **10–15 秒**；坦克一次稳拉 **3–4 只**；
  五人本靠 **羊 / 放逐 / 缠绕 / 陷阱** 推进 → **控制与仇恨仍是核心**。
- 命中与爆击：**近战 / 远程 / 法术合并为一套**，不再分开计算。
- 不加「韧性」属性；治疗加成附带 **1/3 数值的法术伤害加成**。

## 免责声明

> [!warning] 这是 beta 数据
> - 所有数值（伤害、吸收量、冷却）**上线前都可能改**。
> - 部分技能名 / 描述在数据层里仍是英文（如 `Wrack`、`Soul Siphon`、`Litany of Light`），
>   说明该条目还没本地化完，最终中文名可能不同。
> - 天赋的「层 / 列」以模拟器实际布局为准；本 Vault 里的 `r行-c列` 只用于定位，不代表所需点数。
> - 站点本身是**个人整理**，不是官方资料。有冲突时以游戏内为准。

## 本 Vault 里标记的含义

| 标记 | 含义 |
| --- | --- |
| **新增** | 数据层标 `new` —— 经典旧世没有的天赋/技能 |
| 改动 | 数据层标 `changed` —— 相对经典旧世有改动 |
| 位移 | 数据层标 `moved` —— 位置变了 |
| 保持 | 数据层标 `same` |
