# 术士 · 天赋与专精

> [!info] 版本框架
> 三系七层，60 级共 **51 点**。`11 / 21 / 31` 点的核心大招全部保留，
> 另外**每棵树在更深处多出一个全新核心技能**（经典旧世没有的东西）。
> 一批「只堆 BUFF」的过路天赋被移出天赋树，改成职业自带。
> 数据口径见 [[数据来源与版本]]。

---

## 三系速览

| 系 | 玩法定位 | 本版本新核心 |
| --- | --- | --- |
| **痛苦 Affliction** | DoT 铺伤 + 吸取续航 | **摧残 Wrack**（引导，暗影 DoT 增伤 10%） |
| **恶魔学识 Demonology** | 宠物强化 + 极高生存 | **恶魔契约**（牺牲效果不再被重新召唤取消） |
| **毁灭 Destruction** | 直伤爆发 | **烧尽 Incinerate** + **浩劫灾祸 Bane of Havoc**（AoE 溅射） |

## 加点思路（51 点）

> [!note] 这不是「最优解」，是**按键位体系出发**的思路。
> 具体数值请回 [天赋模拟器](https://wx-wow.com/talents.html) 自己推。

### A. 毁灭主流（PVE 输出 / 上手最快）
- **毁灭 ~31–36 点**：吃满 灾祸 → 毁灭 Ruin → 燃烧 → 影与焰 → 烧尽
- **痛苦 ~11–15 点**：镇压（命中 + 减仇恨）、强化腐蚀术（瞬发腐蚀）、邪咒
- **恶魔 余点**：恶魔之拥（耐力 +15%）
- 键位重心：`1 暗影箭` `2 献祭` `5 燃烧` `V 暗影灼烧` `3 腐蚀术`

### B. SL/SL 生存流（PVP / 野外单刷）
- **恶魔 ~30 点**：恶魔之拥 → 邪能活力 → 灵魂链接 → 恶魔学识大师
- **痛苦 ~21 点**：镇压、强化腐蚀术、夜幕、疲劳诅咒
- 键位重心：`F 疲劳诅咒` `C 恐惧嚎叫` `Shift+C 恐惧` `Ctrl+X 牺牲` `Shift+X 防护暗影结界`
- 灵魂链接是**常驻**的，记得开场就开，不要占应急键位

### C. 痛苦持续流（续航 / 长战斗）
- **痛苦 ~36 点**：邪咒 → 恶疾 → Soul Siphon → 暗影掌握 → 摧残
- **毁灭 ~15 点**：灾祸、熔岩之肤（−10% 受伤）
- 键位重心：`1 摧残` `3 腐蚀术` `4 痛苦灾祸` `Shift+3 生命虹吸`
