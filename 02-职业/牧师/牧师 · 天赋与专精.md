# 牧师 · 天赋与专精

> [!info] 版本框架
> 三系七层，60 级共 **51 点**。`11 / 21 / 31` 核心保留，每棵树另有更深层的全新核心技能。
> 本版本**戒律终于有了自己的核心输出/治疗技能：苦修 Penance**，神圣拿到 **愈合祷言**。
> 另外 **防护恐惧结界已成为所有牧师的基础技能**（不再是矮人专属），**噬灵瘟疫改成常规暗影法术**。

## 加点思路（51 点）

### A. 神圣奶（副本主流）
- **神圣 ~31–36**：神圣之怒 → 灵感 → 联结治疗 → 精神指引 → 精神治疗 → 愈合祷言
- **戒律 ~15–20**：强化真言术：盾、灵魂守护、心灵专注、心灵之力、冥想
- 键位重心：`2 快速治疗` `3 恢复` `4 强效治疗术` `5 愈合祷言` `Shift+2 联结治疗`

### B. 戒律盾奶（团队减伤 / PVP）
- **戒律 ~36**：双生戒律 → 强化真言术：盾 → 灵魂守护 → 苦修 → 新生希望 → 神圣庇护 → 能量灌注
- **神圣 ~15**：神圣之怒、法术屏障
- 键位重心：`2 真言术：盾` `Ctrl+2 给自己盾` `5 苦修` `Shift+V 能量灌注`

### C. 暗影（输出 / 单刷 / 团队回蓝位）
- **暗影 ~31–36**：暗影集中 → 强化心灵震爆 → 精神鞭笞 → 吸血鬼的拥抱 → 暗影之波 → 沉默 → 黑暗 → 暗影形态
- **戒律 ~15**：心灵之力、冥想、精神敏锐、心灵专注
- 键位重心：`1 心灵震爆` `2 精神鞭笞` `3 暗言术：痛` `4 噬灵瘟疫` `5 暗言术：灭` `R 沉默`
