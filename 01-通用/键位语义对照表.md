# 键位语义对照表

> 这张表是 [[通用快捷键设置思路]] 的速查版。
> **左列是键，中列是语义（永不变），右列是各职业的实例。**

## 应急区 `Z X C V`

| 键 | 语义 | 术士 | 牧师 |
| --- | --- | --- | --- |
| `X` | **一级保命** | 治疗石（物品宏） | 绝望祷言 |
| `Shift+X` | **二级保命** | 防护暗影结界 | 真言术：盾（自己） |
| `Ctrl+X` | **三级保命 / 保底** | 牺牲（虚空行者护盾）／灵魂石 | 艾露恩的赐福（暗夜）／应急方案（侏儒） |
| `Z` | **驱散 / 解控** | 吞噬魔法（地狱猎犬） | 驱散魔法 |
| `Shift+Z` | 第二驱散 | — | 祛病术 / 驱除疾病 |
| `C` | **群体控制（AoE）** | 恐惧嚎叫 | 心灵尖啸 |
| `Shift+C` | **单体控制** | 恐惧 | 束缚亡灵 |
| `Ctrl+C` | 特种控制 | 放逐术 | 精神控制 |
| `V` | **爆发 / 战斗增益** | 暗影灼烧 / 燃烧（瞬发爆发） | 心灵专注 |
| `Shift+V` | 大爆发（分钟级） | 地狱火（召唤） | 能量灌注 |

## 功能区 `R T F G`

| 键 | 语义 | 术士 | 牧师 |
| --- | --- | --- | --- |
| `R` | **打断 / 沉默** | 法术封锁（宠物宏） | 沉默（暗影天赋） |
| `T` | **降仇恨 / 脱战** | 相位变换 / 掉宠 | 渐隐术 |
| `F` | **减速 / 风筝** | 疲劳诅咒（天赋） | 精神鞭笞 |
| `G` | **宠物 / 守护 / 保护** | 召唤宠物（智能宏） | 防护恐惧结界 |
| `Shift+G` | 次级守护 | 生命通道 | 防护暗影 |

## 主循环区 `1 2 3 4 5`

| 键 | 语义 | 术士（毁灭） | 牧师（神圣） |
| --- | --- | --- | --- |
| `1` | 主填充 / 主直伤 | 暗影箭 | 惩击 |
| `2` | **最高频** 技能 | 献祭 | 快速治疗 |
| `3` | 持续伤害 / 持续治疗 | 腐蚀术 | 恢复 |
| `4` | 第二 DoT / 大治疗 | 痛苦灾祸 | 强效治疗术 |
| `5` | 短 CD 爆发键 | 燃烧 | 愈合祷言 |

## 低频区

| 键 | 语义 |
| --- | --- |
| `6` | AoE（火焰之雨 / 地狱烈焰 / 神圣新星 / 治疗祷言） |
| `~` | 资源循环（生命分流 / 黑暗献祭） |
| `Shift+1..5` | 同位技能的变体（换等级、换目标） |
| `Ctrl+1..5` | 同位技能对自己 / 对焦点 |
| `Alt+*` | 团队与非战斗：复活、buff、仪式、制造 |

## 鼠标

| 键 | 语义 |
| --- | --- |
| 侧键 `4` | 第二打断 / 最高频瞬发 |
| 侧键 `5` | 第二保命 / 生命分流 |
| `Shift+侧键4` | 设焦点目标 |
| 中键 | 自我施法开关 / 目标自己 |
