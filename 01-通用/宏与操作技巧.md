# 宏与操作技巧

> [!warning] 先确认宏条件语句能不能用
> 下面的写法用的是 `[条件]` 式宏语法（`@mouseover`、`@focus`、`modifier:` 等）。
> **进游戏后先拿一条最简单的试一下**：
> ```
> /cast [@player] 真言术：韧
> ```
> 能正常对自己释放 → 条件语句可用，本页全部适用。
> 报错或原样当技能名处理 → 客户端是旧式宏，本页只保留「一键多用」思路，条件部分要改用插件实现。

---

## 1. 让键位语义成立的三类宏

### ① 自我施法宏 —— 把 `Ctrl+` = 对自己 落实

```
#showtooltip
/cast [mod:ctrl,@player][] 真言术：盾
```
按 `2` 给目标，按 `Ctrl+2` 给自己，**共用一个键**。
这是「修饰键统一含义」能省键位的关键。

### ② 鼠标指向宏 —— 治疗职业的命根子

```
#showtooltip
/cast [@mouseover,help,nodead][@target,help,nodead][@player] 快速治疗
```
优先级：鼠标悬停的友方 → 当前友方目标 → 自己。
**不用切目标就能奶人**，暗影形态下打怪同时奶队友也靠它。

### ③ 焦点宏 —— 打断 / 控制专用

```
#showtooltip
/cast [@focus,harm,nodead][] 法术封锁
```
配合设焦点的宏：
```
/focus
```
绑 `Shift+鼠标侧键4`。先焦点敌方治疗/法师，之后 `R` 永远打断他，**不用切目标**。

## 2. 保命键（`X`）的宏写法

保命键最怕「按了没生效」。用 `/use` + `/cast` 串起来做**兜底**：

术士 `X`：
```
#showtooltip 治疗石
/use 治疗石
/use 治疗药水
```
（治疗石是 30 分钟内有效的物品，登出 15 分钟就消失 —— 记得开荒前重做一批。）

牧师 `X`：
```
#showtooltip 绝望祷言
/cast 绝望祷言
```

> [!tip] 不要在保命宏里加 `/stopcasting` 以外的多余行
> 保命宏越短越好。一行 `/cast`，最多前面加一行 `/stopcasting` 打断当前读条。

---

## 3. 停止施法（读条职业必备）

```
#showtooltip
/stopcasting
/cast 恐惧嚎叫
```
所有**打断自己读条去救急**的技能都该加 `/stopcasting`：群控、保命、打断。
反过来，**主循环技能绝对不要加** —— 不然会自己把自己的暗影箭掐掉。

---

## 4. 宠物宏（术士专用）

一键智能召唤：
```
#showtooltip
/cast [nopet] 召唤虚空行者
/petattack
```

宠物技能挂自己键位（宠物条不该占核心键）：
```
#showtooltip 法术封锁
/cast [@focus,harm][] 法术封锁
```

> [!note] 宠物技能要关自动施放
> 折磨（虚空行者）保持自动，**法术封锁 / 吞噬魔法 / 诱惑必须关掉自动**，否则关键时刻在 CD。

---

## 5. 界面与操作习惯

- **关掉「自动瞄准」式点击施法**，全部走键位 + 鼠标指向宏。
- 动作条建议：主条（`1-6`）放主循环，第二条（`Shift+1-6`）放变体，**第三条整条隐藏**，只做宏容器。
- 团队框架（Grid / VuhDo 类插件）开**鼠标指向**，配合 §1.② 的宏。
- `空格` 只跳跃，**不要绑技能** —— 跳跃甩尾转身在本版本拉怪时会用。
- 打开「**始终显示动作条快捷键文字**」，排键位期间靠它纠错，练熟后再关。

---

## 6. 练键位的方法

1. 新键位排好后，**先去打 20 只白怪**，强迫自己每只都按一次 `X` 和 `C`（哪怕没必要）。
2. 进 5 人本前，对着木桩把 `R`（打断）按 10 次。
3. **一周内不要改键位**。改来改去等于永远没有肌肉记忆。
4. 真要改，一次只改一个键。
