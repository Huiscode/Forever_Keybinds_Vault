# 通用快捷键设置思路

> [!abstract] 一句话
> **同一个物理键，在所有职业上永远放同一「种」技能。**
> 你练的不是「按 X 放暗影结界」，而是「**X = 我要活下来**」。

---

## 1. 为什么要按「语义」而不是按「技能」排

传统排法是「1234 顺着动作条往下放」，问题在于：

- 换职业要从零重学，肌肉记忆作废；
- 紧急情况下大脑要做两次转换（「我快死了 → 我的保命技能叫什么 → 它在几号键」）；
- 同一职业换个专精，键位又要洗一遍。

按语义排之后，紧急情况只剩一次转换：**「我快死了 → X」**。
术士按 X 是治疗石，牧师按 X 是绝望祷言，法师按 X 是寒冰屏障 —— 手不用知道区别。

---

## 2. 核心公理：`X = 保命`

`X` 是整套体系的锚点，规则很硬：

> [!warning] X 键三原则
> 1. **X 上永远是「按下去就能多活几秒」的技能**，不是治疗、不是减伤 buff、不是回血 buff。
> 2. **X 必须是瞬发**（或接近瞬发）。需要读条的保命不配占 X。
> 3. **X 永远不放进常规循环**。它一整场可能只按两次，但那两次决定生死。

分层（按「有多急」往上叠修饰键）：

| 键 | 含义 | 说明 |
| --- | --- | --- |
| `X` | **一级保命** | 最短冷却、最常按的那个。血掉到 ~50% 就可以按 |
| `Shift+X` | **二级保命** | 冷却更长、效果更强。血到 ~30% |
| `Ctrl+X` | **三级保命 / 保底** | 分钟级大冷却，或「死了还能赖一下」的东西 |

为什么选 `X`：左手自然放在 WASD 上时，无名指/小指到 `X` 只有一格，**不需要移开视线也不需要松开移动键**。`Z` 太靠外（小指要伸），`C` 要跨过来（食指区更适合放主动控制）。

---

## 3. 键位分区（左手不离 WASD）

```
  ~  1  2  3  4  5  6
      Q  W  E  R  T  G
       A  S  D  F
        Z  X  C  V
```

| 区 | 键 | 用途 |
| --- | --- | --- |
| **移动区** | `W A S D` `Q E` | 只走位，**绝不放技能**。`Q/E` 保持侧移（strafe），不要留给转身 |
| **主循环区** | `1 2 3 4 5` | 战斗里按得最多的 3–5 个输出 / 治疗技能 |
| **功能区** | `R T F G` | 打断、降仇恨、减速、宠物/守护 |
| **应急区** | `Z X C V` | 驱散、保命、群控、爆发 |
| **低频区** | `6` `~` `Shift+数字` `Ctrl+数字` | Buff、召唤、制造、坐骑、长 CD |
| **鼠标** | 侧键 `4/5`、`Shift+滚轮` | 高频瞬发技能 / 焦点目标 |

> [!tip] 拇指去哪了
> `空格` = 跳跃不动。侧键 4/5 用拇指，是**除了 1234 之外最快的两个键**，留给「一秒都不能晚」的技能（打断、保命备份、Life Tap 这类超高频瞬发）。

---

## 4. 修饰键的统一含义

| 修饰键 | 含义 | 例子 |
| --- | --- | --- |
| 无 | 对当前**敌方**目标 / 默认行为 | `3` = 对敌人上 DoT |
| `Shift+` | **更强 / 更长 CD** 的同类技能 | `Shift+X` = 大保命 |
| `Ctrl+` | **对自己** 或 **对焦点目标** | `Ctrl+2` = 给自己套盾 |
| `Alt+` | 少用。留给**团队 / 非战斗**（复活、buff、仪式） | `Alt+R` = 复活 |

规则只有一条：**四个职业上的 `Shift+X` 必须是同一类东西**，否则整套体系就白建了。

---

## 5. 排键顺序（新职业上手照这个走）

1. **先钉死 `X` / `Shift+X`** —— 翻技能书，找「掉血时按的瞬发」。
2. **再钉 `R`（打断）和 `C`（群控）** —— 这两个是本版本 5 人本推进的核心。
3. **再排 `1–5` 主循环** —— 按「按得最多」排序，最高频放 `2`（食指自然位），不是 `1`。
4. **`F` 放减速/风筝**，`T` 放降仇恨/脱战。
5. 剩下的全部丢 `Shift+数字` / `6` / `~`。
6. **空出来的键宁可空着**，别硬塞。空位＝将来加技能的余量。

> [!danger] 常见错误
> - 把保命技能放在 `Shift+6` —— 等你按到已经死了。
> - 把 buff（韧、心灵之火、恶魔护甲）放在主循环区 —— 它们一小时按一次，占着核心键位是浪费。
> - `Q/E` 设成转身 —— 本版本要靠走位躲和拉怪，侧移不能丢。

## 6. 校验清单

排完键位，对着问自己：

- [ ] 血条一红，手指**不看屏幕**能摸到 `X` 吗？
- [ ] 敌方法师开始读条，`R` 能在 1 秒内按出去吗？
- [ ] 同时被 3 只怪咬住，`C` 是不是群控？
- [ ] 仇恨拉高了，`T` 是不是降仇恨？
- [ ] 主循环里有没有需要**松开移动键**才能按到的键？（有就换）
- [ ] 换到另一个职业，前五条的答案是不是**一模一样**？
